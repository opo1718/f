# Undangan Walimatul Khitan Faariz

Website undangan digital Walimatul Khitan Muhammad Faariz Al-Khowarizmi.

## Teknologi
- HTML, CSS, dan JavaScript
- Progressive Web App (PWA)
- Siap dipublikasikan melalui Cloudflare Pages atau GitHub Pages (setelah seluruh aset proyek diunggah).

## Fitur
- Countdown acara
- RSVP dan buku tamu
- Galeri foto
- Peta lokasi
- Nama tamu otomatis
- Musik latar
- Halaman generator tamu dan dashboard pengelolaan
